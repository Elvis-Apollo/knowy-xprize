# XPRIZE Submission Checklist

Deadline: August 17, 2026 at 1:00 p.m. PDT.

## Technical pass/fail

- [ ] Public production URL works without local setup.
- [ ] At least one deployed request visibly shows `Gemini · gemini-2.5-flash`.
- [ ] Vertex AI is configured and visible in Google Cloud API usage records.
- [ ] Account decision includes status, next action, and citations.
- [ ] Reuse flow works.
- [ ] Source-change and refresh flow works.
- [ ] `/api/executions` returns production execution evidence.
- [ ] Repository is public, or shared with `testing@devpost.com` and `judging@hacker.fund`.
- [ ] Testing instructions include the public URL and exact demo steps.

## Three-minute video

- [ ] Under three minutes and publicly visible on YouTube, Vimeo, or Youku.
- [ ] Shows the deployed product, not only slides.
- [ ] Shows Gemini generating the decision.
- [ ] Shows citations and account health.
- [ ] Shows execution ID/log.
- [ ] Shows reuse.
- [ ] Shows source change and refresh.
- [ ] Explains the Small Business Services impact.
- [ ] Uses no unlicensed music or third-party marks.

## Business evidence — must be genuine

- [ ] Arms-length third-party customers identified with consent.
- [ ] Number and profile of real users.
- [ ] Written customer feedback or testimonial with permission to share.
- [ ] Total revenue during the submission period.
- [ ] Revenue broken out by May, June, July, and August 2026.
- [ ] Related-party revenue reported separately.
- [ ] Total expenses documented.
- [ ] Marketing/customer-acquisition spend disclosed, even if zero.
- [ ] Simple P&L prepared.
- [ ] Corporate ID included if entering as an organization.

## Written submission

- [ ] Category selected: Small Business Services.
- [ ] 500–1000 word AI-native operations narrative completed.
- [ ] Human versus AI responsibilities explained.
- [ ] Jobs and economic opportunity created or enabled explained.
- [ ] Pre-existing prototype usage disclosed.
- [ ] Repository URL added.
- [ ] Production URL and test instructions added.
- [ ] Video URL added.

## Privacy

- [ ] No API keys or access tokens committed.
- [ ] No private customer records committed.
- [ ] Customer evidence shared only through the appropriate private submission channel.
- [ ] Customers know what information will be shared with judges.
